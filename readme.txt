== Description ==

WP Shadcn is a modern, lightweight WordPress theme built with Shadcn UI components and contemporary web technologies. Designed for developers and content creators who value clean code and excellent user experience. This theme emphasizes performance, accessibility, and ease of customization.

== Features ==

* Modern block-based theme architecture
* Dark mode support
* Responsive design
* Clean and semantic HTML
* Performance optimized
* Built with Shadcn UI principles
* Customizable color palette
* Full-width and centered layout options
* Footer and header customization
* Custom block patterns for quick content creation

== Installation ==

1. Upload the `shadcn` folder to your WordPress themes directory (usually `/wp-content/themes/`)
2. Go to Appearance > Themes in the WordPress admin dashboard
3. Find "WP Shadcn" and click "Activate"
4. (Optional) Go to Appearance > Editor to adjust theme settings

== Getting Started ==

2. **Configure Theme Settings**: Adjust header and footer content through the WordPress Site Editor
3. **Create Content**: Use the included block patterns for quick page creation
4. **Dark Mode**: The theme includes built-in dark mode support that respects user preferences

== Frequently Asked Questions ==

**Q: Does this theme support dark mode?**
A: Yes! The theme includes built-in dark mode support that automatically detects user system preferences.

**Q: Can I customize the colors?**
A: Yes, you can customize colors through the WordPress Customizer (Appearance > Customize).

**Q: Is this theme SEO friendly?**
A: Yes, the theme follows WordPress best practices and semantic HTML standards for better SEO.

**Q: How do I use the block patterns?**
A: When creating or editing pages/posts, look for the "Patterns" section in the Block Editor to insert pre-designed content blocks.

== Changelog ==

= 1.2.0 =
* Added: Layout picker for the Mini-Cart and Checkout blocks. Select the block in the editor and use "Change layout" in its toolbar to browse the layouts and apply one.
* Added: 6 Mini-Cart drawer layouts - Grid 2 Columns, Card List, Compact, Large Thumbnail, Bold Header and Summary. Each one ends with a "You might also like" strip of best sellers, with an add to cart button.
* Added: 6 Checkout layouts - Two Column, Summary First, Single Column, Stepped, Compact and Wide Summary.
* Added: WooCommerce templates for product archives, single products, product taxonomies, order confirmation and product search results, plus blog archive and coming soon templates, backed by new query loop, product loop, product archive and related products patterns.
* Updated: The theme's WooCommerce styles now load in the editor as well, so the Cart and Checkout blocks are laid out on the canvas the way they appear on the site.
* Updated: The cart and checkout templates are now named page-cart and page-checkout so they resolve as page templates.
* Fixed: The Mini-Cart drawer and its badge kept the colours of the mode the page loaded in after switching between light and dark mode. The badge was invisible on a dark header even before switching.
* Fixed: The item count on Checkout order summary lines was unreadable in dark mode.
* Fixed: Form labels shifted down as soon as a field took a value, visible on the Cart coupon field and on the prefilled Checkout email field.
* Fixed: Product cards in a row ended at different heights when a product had no price, and the add to cart button was centred instead of aligned with the title and price.
* Fixed: Cart and Mini-Cart thumbnails sat flush against the row border, and the quantity plus button overlapped the remove icon.
* Fixed: The separator on single product pages rendered as a short centred rule.

= 1.1.0 =
* Added: Shadcn AI in the block editor. The panel offers a one-click install of the Shadcn Blocks plugin, which ships the blocks the patterns are built from and the prompt-to-layout builder itself.

* Added: Testimonial 12 pattern.
